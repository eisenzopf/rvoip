Wideband G.711: PCMU and PCMA sampled at 16 kHz on a dynamic payload type
(`121 PCMU/16000`, `120 PCMA/16000`). It is opt-in: list `120` and/or `121`
in `Config::offered_codecs`. An answer matches it by rtpmap and prefers it
over 8 kHz G.711. `EndpointCall::negotiated_media()` reports the negotiated
sample rate, so frames can be sent at 16 kHz. This is not G.711.1
(`PCMU-WB`/`PCMA-WB`).
